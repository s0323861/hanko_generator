# Hankoツクール

登録不要・無料で使える、Web電子印鑑作成ツールです。  
認印・角印・日付印を作成し、背景が透明なPNG画像としてダウンロードできます。

## 主な機能

- 認印（丸印）、角印（社印）、日付印に対応
- 文字・日付・印影色・書体を選択可能
- 入力内容を画面上へリアルタイム表示
- 透過PNG形式でダウンロード
- パソコン・スマートフォン対応
- 登録不要・無料

## 使い方

1. 印鑑の種類を選びます。
2. 名前、会社名、日付などを入力します。
3. 色と書体を選び、プレビューを確認します。
4. 「電子印鑑を作成＆ダウンロード」を押します。

ダウンロードしたPNG画像は、Word、Excel、PDFなどの書類へ挿入できます。

## 動作環境

- PHP
- GDライブラリ
- mbstring
- JavaScriptが利用できるWebブラウザ

## 設置方法

このリポジトリのファイルとフォルダを、そのままPHP対応のWebサーバーへアップロードしてください。

## プライバシー

入力内容は印鑑画像を作成するためにのみ使用します。生成された一時画像は、ダウンロード送信後にサーバーから削除されます。
